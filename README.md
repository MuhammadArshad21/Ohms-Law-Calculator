# Ohms-Law-Calculator
A beginner-friendly Python project that combines programming fundamentals with basic electrical concepts. This command-line calculator uses Ohm’s Law and power formulas to calculate voltage, current, resistance, and power while practicing loops, conditionals, user input, and basic validation.

Ohm's Law Calculator

My first Python project combining programming fundamentals with basic electrical concepts.

About the Project
This is a command-line calculator that performs basic electrical calculations using Ohm's Law and electrical power formulas.
Features
•	Calculate Current using Voltage and Resistance
•	Calculate Resistance using Current and Voltage
•	Calculate Voltage using Current and Resistance
•	Calculate Power using different combinations of electrical values
•	Repeat calculations without restarting the program
•	Exit the calculator when finished
Concepts Used
Electrical Concepts
•	Ohm's Law: V = IR
•	Power: P = VI
•	Power: P = I²R
•	Power: P = V²/R
Python Concepts
•	Variables
•	User input
•	Type conversion
•	Conditional statements
•	While loops
•	Break statements
•	Basic input validation
What I Learned
This project helped me understand how an engineering formula can be converted into a logical sequence and then implemented as a working program.
I also learned that making a program work is only the first step — testing different inputs and handling the user's choices are equally important.
